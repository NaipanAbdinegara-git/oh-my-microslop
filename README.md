# oh-my-microslop

> "Because your system was too fast, we fixed it."

## Overview
**oh-my-microslop** is an interactive telemetry simulation tool. It is designed to demonstrate how modern software collects system data under the guise of "improving user experience." This program enforces strict EULA compliance, performs real-time telemetry harvesting, and engages users in mandatory security interrogations.

---

## ⚠️ Disclaimer
This project is created **SOLELY for educational and satirical purposes**.
- No personal data is transmitted to any external servers.
- All logs are stored locally (`system_information.csv`, `usr_activities.log`, `user_data.csv`).
- Any resemblance to actual corporations or data harvesting practices is purely satirical.

---

## Key Features
* **EULA Enforcement**: Forces users to acknowledge terms they'll never read.
* **Telemetry Harvesting**: Captures OS, CPU, RAM, and Battery metadata in real-time.
* **Security Interrogation**: Challenges users with existential security questions.
* **Local Logging**: Maintains a comprehensive log of all user interactions for "corporate analysis."
